# Android 版 · 真机验收清单（最终门禁）

> 前置：安装最新 APK（`android/dist/app-debug.apk` 或 GitHub Actions 产物）。
> 安装方法：APK 传到手机（数据线/微信文件传输助手/网盘）→ 点击安装 → 允许"未知来源"。**勿在微信内点开安装包链接，用系统文件管理器。**

## 0. 准备

- [ ] 手机安卓版本 ≥ 8.0（设置→关于手机）；
- [ ] 系统定位服务已开；
- [ ] 记录前完成白名单引导页的操作。

## 1. A-M1 记录闭环（核心）

- [ ] 点「开始拜年」→ 授权定位 → 状态卡显示"已定位 · 精度约 ±X 米"（X 在 3~15 为 GPS 正常）；
- [ ] 走一段 → 到某处按「到一户了 · 暂停」→ 户数 +1；「继续出发」→ 继续；
- [ ] **锁屏 10 分钟揣兜里走** → 解锁 → 轨迹连续无断点；
- [ ] 通知栏常驻"拜拜 · 拜年记录"，文案随状态变化；
- [ ] 回家按「结束拜年」（距家远会弹确认）→ 自动进入回顾页；
- [ ] **强杀测试**：最近任务划掉 App → 重开 → 弹"检测到未完成的拜年记录"→ 继续 → 数据完整；
- [ ] 拒绝定位权限 → 出现中文提示。

## 2. A-M2 回放与收拾

- [ ] 回顾页「▶ 播放」：默认「总览」档快速看完整个路线（全程 ≤20 秒），可切 1x/2x/4x/8x；
- [ ] 回放画布：金色「家」字在圆内清晰可见，不与任何元素重叠；
- [ ] 改名：输入名字 → 改名生效，画布标签更新；
- [ ] 合并：点选两个芯片 → 合并按钮亮 → 合并后户数 -1；
- [ ] 拆分：到访 2 次的户出现"拆第 1/2 次"按钮 → 拆分生效；
- [ ] 跳变点：剔除全部后回放不再跳动。

## 3. A-M3 优化与压轴

- [ ] 回顾页「三线对比」→ 成绩单四卡数字合理（三线都比实走省）；
- [ ] 三线标签切换 → 虚线=估算段、实线=实走段；
- [ ] 「▶ 推演」逐段点亮；「✨ 压轴动画」3 秒 morph 成金色星图。

## 4. A-M4 跨年便利

- [ ] 记录页「清单」→ 从去年导入（有去年数据时）/ 手动添加 / 改名 / 删除；
- [ ] 回顾页漏访检查：清单里的户没去 → 红色"❌ XX 没去！"；
- [ ] 套名：候选芯片点击 → 户名立即套用。

## 5. 地图 / 轻提示 / 日期（二轮新增）

- [ ] 记录页地图卡：**高德瓦片秒开可见**（不是占位图）；右上角「地图/卫星」切换都出图；双指缩放可用；
- [ ] 记录中：当前位置红点 + 精度圈实时跟随；走过的段淡红、**当前段实红粗线实时增长**（像导航）；金色「家」与红圈户标正常；地图折叠/展开后轨迹不丢；
- [ ] 开始拜年前（等待定位时）：地图显示当前位置；
- [ ] 时间计时：开始拜年后「本次用时」从 0 稳定走秒，不回跳不卡 0；
- [ ] 定位精度：到家门口点结束 → 大概率直接结束（≤20m 不弹确认）；弹确认时距离接近真实值（不再虚高十几米）；
- [ ] 断网/瓦片失败：显示「地图暂不可用」兜底提示 + 轨迹标记照常绘制；
- [ ] 轻提示：点「走路/骑车」等 → 顶部白底金边胶囊弹出（不遮挡底部导航），约 2.4s 自动消失；
- [ ] 顶部金色徽章：点开 → 日期选择器；选初二/初三等 → 徽章显示「大年初X」，非春节时段显示「M月d日」；结束拜年 → 回顾页标题用所选日期；
- [ ] 白名单引导页：自动识别机型置顶（标「你的机型」）→ 点卡片直达对应系统设置页；跳不过去会弹系统「允许后台高耗电」授权框，且设置路径已复制到剪贴板；
- [ ] 结束拜年 → 回顾页回放默认「总览」快速放完。

## 6. P0 离线预载（飞行模式验证）

- [ ] 连网状态下开始拜年 → 顶部提示「正在预载周边地图…」→ 完成后提示「已预载 N 张瓦片」；
- [ ] 地图卡头部「预载」按钮：无记录时点 → 提示先开始拜年；有记录后点 → 重新预载并提示张数；
- [ ] **飞行模式**（关 WiFi/流量）→ 杀掉 App 重开 → 记录页地图卡：村周边普通地图完整可见（卫星图同理可切）；
- [ ] 飞行模式下开始拜年 → 轨迹/当前位置/家户标记照常绘制（底图不动线照画）；
- [ ] 网页版（https://chenchen913.github.io/baibai/）：开始拜年后自动预载；点「预载」按钮；飞行模式刷新页面后地图仍可见。

## 7. A-M5 互通

- [ ] 历史页「导出 JSON」→ 分享到微信/网盘成功；
- [ ] 电脑网页版导出 → 传到手机 → 历史页「导入 JSON」→ 列表出现该记录，回放/三线对比与网页版一致；
