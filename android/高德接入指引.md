## 1. 当前实现

| 环节 | 方案 |
|---|---|
| 地图引擎 | 内置 Leaflet（android/app/src/main/assets/baibai_map/，随 APK 打包，不依赖远程 JS） |
| 瓦片 | **高德瓦片（免 Key）**：普通地图（矢量 style=8）+ **卫星图（style=6）**，地图右上角「地图/卫星」一键切换；失败自动回退 OSM |
| 坐标系 | 系统定位 WGS-84 → **GCJ-02**（map.html 内置 wgs2gcj）后渲染，与高德瓦片严格对齐 |
| 容器 | RecordScreen.kt 的 MapCard：WebView 加载 assets/baibai_map/map.html，evaluateJavascript 单向桥 |
| 实时位置 | 白描边红点 + 精度圈 + 自动跟随居中；等待首个定位期间也实时显示当前位置 |
| 实时轨迹 | **分段渲染**：走过的段淡红、当前段实红粗线实时增长（像导航走过的路线）；全量同步 + 每 1.2s 增量跟随（按时间戳去重） |
| 标记 | 金色「家」+ 红圈数字户标（悬浮户名） |
| 降级 | 瓦片失败自动回退 OSM；高德+OSM 全部失败时显示「地图暂不可用」可见兜底浮层，轨迹与标记照常绘制；已缓存瓦片离线可看（TileCache 磁盘缓存 + 预载，审核报告 P1~P7 已修复） |

- 权限：INTERNET（已有）；无需 SHA1/包名绑定、无需实名申请。
- 版权注：© 高德地图 / OpenStreetMap；折叠/展开、默认中心（潍坊 36.71, 119.1）保留设计规范。

## 2. 瓦片选型说明（国内可用性第一）

- 首版用 OSM 瓦片，但 tile.openstreetmap.org 在国内慢/不稳——用户实测"看不到地图"，故主瓦片换高德；
- 高德瓦片是 GCJ-02 火星坐标，已内置 wgs2gcj 转换；网页版同步同一转换（src/wgs2gcj.ts，有单测）；
- 高德 SDK Key 有实名/SHA1/包名门槛，瓦片直链免 Key——个人玩具零成本零门槛。

## 3. 定位侧

定位用系统 LocationManager（SystemLocationSource，GPS + 网络双源，A-M1 决策 + 二轮增强）；
不依赖高德定位 SDK；后续更高精度可在 LocationSource 抽象上加实现。

## 4. 可选升级（不需要就不动）

想换成别的瓦片源，只需改 map.html 里的 sources 数组；应用层代码（RecordScreen/MapCard/JSON 桥）一行不用改。
