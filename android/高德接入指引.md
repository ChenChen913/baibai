# 高德地图/定位 Key 接入指引

> 现状：A-M1~A-M5 全程使用**系统 LocationManager**（免 Key）。高德能带来：村庄级路网地图、基站/WiFi 辅助定位（室内更快出点）。**非必需**——接入是可选增强。

## 1. 申请 Key（免费，个人开发者）

1. 打开 [高德开放平台](https://lbs.amap.com/) → 注册/登录（实名认证）；
2. 控制台 → 应用管理 → 创建应用；
3. 添加 Key：服务平台选「**Android 平台**」；
4. 填写三项：
   - **发布版安全码 SHA1**：命令行 `keytool -list -v -keystore <你的签名文件>` 获取（正式签名后）；
   - **调试版安全码 SHA1**：`keytool -list -v -keystore %USERPROFILE%\.android\debug.keystore -alias androiddebugkey -storepass android`；
   - **PackageName**：`io.github.chenchen913.baibai`（与 build.gradle.kts 的 applicationId 一致，改包名则重新申请）。

## 2. 接入点（代码位置）

| 文件 | 改动 |
|---|---|
| `app/build.gradle.kts` | 添加高德依赖（map/location SDK，按官网版本） |
| `AndroidManifest.xml` | `<meta-data android:name="com.amap.api.v2.apikey" android:value="你的Key"/>` + 定位权限（已有） |
| `LocationSource.kt` | `AmapLocationSource` 占位类实现：AMapLocationClient 连续定位 1s → 回调转 `Fix` |
| `RecorderHub.init` | `source = AmapLocationSource(context)`（替换 SystemLocationSource） |
| 地图展示 | 后续可选：记录页加高德 MapView（A-M5 之后的事） |

## 3. 为什么当前不强制接

- 记录本身只依赖坐标，地图展示是"参与感"加成；
- 系统 GPS 在村庄开阔环境精度 3~10 米，足够本场景；
- 省去 Key 申请/调试 SHA1 的配置成本——**先把全链路跑通，Key 到位随时可插**（接口已预留）。

## 4. 高德定位参数建议（接入时）

连续定位模式 · 间隔 1000ms · GPS 优先 + 网络辅助 · 坐标 WGS84（高德 GCJ-02 需转换，注意与网页版/OSM 的坐标系一致性！**转换函数必须进契约文档**）。
