# 安卓地图接入说明（已实现：免 Key · 免费 · 开箱即用）

> **状态更新（2026-08-14，二轮）**：记录页真地图已接入，**无需任何 Key**——
> 采用 WebView + Leaflet + OpenStreetMap（与网页版同一套地图方案），
> 申请高德 Key 的急迫性解除。高德可作为后续可选升级（见 §4）。

## 1. 当前实现（零配置，装上就能看到地图）

| 环节 | 方案 |
|---|---|
| 地图引擎 | 内置 Leaflet（android/app/src/main/assets/baibai_map/，随 APK 打包，不依赖远程 JS） |
| 瓦片 | OpenStreetMap 标准瓦片（tile.openstreetmap.org，免费免 Key）；失败自动切换到 OSM-HOT 备源 |
| 容器 | RecordScreen.kt 的 MapCard：WebView 加载 assets/baibai_map/map.html，Android ↔ JS 单向桥（evaluateJavascript） |
| 实时轨迹 | 全量同步（状态/户数变化/重新展开时）+ 增量跟随（每 1.2s 推最新点，按时间戳去重） |
| 标记 | 白描边红点（当前位置）+ 精度圈 + 红色轨迹线 + 金色「家」+ 红圈数字户标（悬浮户名） |
| 降级 | 无网/瓦片全失败：暖色纸底兜底，轨迹与标记照常绘制；已缓存瓦片离线可看（HTTP 缓存） |
| 坐标系 | 系统 LocationManager 输出 WGS-84，与 OSM 天然一致，无 GCJ-02 转换问题 |

- 需要的权限：INTERNET（已有）；无需 SHA1/包名绑定、无需实名申请。
- 折叠/展开、版权注、待机默认中心（潍坊 36.71, 119.1）全部保留设计规范。

## 2. 网页版同步升级

网页版 src/map-ui.ts 同步做了两处：关掉 Leaflet 自带加减缩放控件（设计稿 zoomControl: false，手机用双指缩放）；瓦片失败自动切换 OSM-HOT 备源。

## 3. 为什么不直接用高德

1. Key 门槛：高德 Key 需实名认证 + 与包名/SHA1 绑定；签名变化（如换机器构建）会让 Key 失效；
2. 坐标系：高德输出 GCJ-02 火星坐标，与网页版/OSM（WGS-84）不一致，必须全链路转换；
3. 体验收益：对"自己村里走一圈"的个人玩具，OSM 乡镇路网 + 轨迹红线 + 家/户标记已完全够用。

## 4. 可选升级：换高德瓦片（不换容器）

以后如果觉得 OSM 瓦片加载慢，只需改一个文件——assets/baibai_map/map.html 里的 sources 数组，
换成高德瓦片地址（webrd01-04.is.autonavi.com 系列，Web 端 JS API 免 Key，但需遵守高德瓦片服务条款），
并把定位坐标由 WGS-84 转为 GCJ-02（转换函数进契约文档后两端同步）。
应用层代码（RecordScreen/MapCard/JSON 桥）一行不用改。

## 5. 定位侧

定位仍用系统 LocationManager（SystemLocationSource，A-M1 决策），不依赖高德定位 SDK；
后续若要更高精度，可在 LocationSource 抽象上加实现。
