# baibai 项目 · UI 设计提示词（Prompt for UI Designer AI）

> 用途：本文件是交给"专门设计 UI 的 AI"的完整需求说明。请先通读业务（§1~§2），再按设计语言（§3）、逐页要求（§4）与状态规则（§5）输出设计；红线（§6）不可违反；交付物见 §7。

## 1. 项目概况（30 秒理解业务）

**baibai（拜拜）**：乡村拜年轨迹复盘玩具。大年初一走村串户拜年时，手机**锁屏揣兜里**持续记录真实行走轨迹；到一户按「暂停」、离开按「继续」；拜完年后回放当日路线，用路径规划算法算出"当日最优走法"与"飞行直线最优"，三线动画对比——**看看自己今年绕了多少路**。

- **用户**：作者本人（单人使用、安卓手机）；
- **一天的使用节奏**：出门前（看清单）→ 拜年中（只按两个键：暂停/继续）→ 拜年后（回家复盘：回放、收拾、三线对比、压轴动画）；
- **情感基调**：春节的喜庆 + 数据的爽感 + 高级感（不是卡通、不是廉价）；
- **双端**：网页版（复盘/演示）+ 安卓版（现场记录）。本提示词主要面向**安卓版（Jetpack Compose）**，设计语言两端通用。

## 2. 现状与问题

当前 UI 已实现全部功能但**视觉粗糙**：按钮堆叠、间距随意、状态层次不清、图标用 emoji、无设计系统。**功能逻辑不动，只做视觉与交互质感升级。**

## 3. 设计语言总纲（必须遵守）

| 项 | 规范 |
|---|---|
| 基调 | **白天暖色年味**：明亮、温暖、喜庆但不俗气；**禁止暗色/黑夜模式**（拜年是大白天） |
| 背景 | 米白→淡橙多层渐变（#FFF8EE → #FFE9D4 → #FFDFC2），可加极淡的暖色径向光晕 |
| 主色 | 朱红 `#C8402F`（主操作/强调）、鎏金 `#E8A23D`（次级/高亮/压轴）、墨棕 `#5A3A2A`（文字） |
| 卡片 | 玻璃拟态：白底半透明（约 66%）+ backdrop 模糊 + 1px 暖色描边 + 大圆角（22dp）+ 柔和阴影 |
| 主按钮 | 红→橙→金横向渐变、全宽、高度 ≥56dp、圆角胶囊、按压微缩放；**同一时刻只显示一个主按钮** |
| 次级按钮 | 幽灵样式：透明底 + 暖色描边；**禁用态 = 置灰 + 半透明（约 38%）+ 不可点击** |
| 图标 | **线性 SVG 图标**（描边 1.8、圆角端点，随文字颜色），**禁用一切 emoji 作按钮图标** |
| 装饰 | 页面边缘可点缀**虚化低透明（约 20%）的礼花/炮仗**图案，绝不进主体区域，最多两样 |
| 排版 | 状态大字 30sp/800 字重；大数字统计用等宽数字；辅助文字 12~13sp 低对比度 |
| 反馈 | 所有按钮：按压动效 + 操作后 toast；关键动作震动 |

## 4. 逐页要求（共 6 页）

### 4.1 记录页（驾驶舱，主页面）
从上到下：
1. **品牌栏**：左"🧧 拜拜"+ 副标题"拜年轨迹复盘"；右金色徽章"大年初一"；
2. **状态大卡**（玻璃卡）：状态大字（待机/记录中/在某户/已保存）+ 一行副文案（如"已定位 · 精度约 ±5 米"）+ 两列大数字统计（拜访户数 / 本次用时）；
3. **实时地图卡**：高德/OSM 风格地图 + 当前定位点（红点+精度圈）+ 已走轨迹红线 + 金色"家"标记 + 红圈数字户标记；底部一行小字版权注；
4. **主按钮区**：按状态只显示一个主按钮——`待机→开始拜年`、`记录中→到一户了·暂停`、`在某户→继续出发`、`记录中/在某户→结束拜年`；旁侧小按钮：撤销（记录中/在某户）、导出；
5. **工具条**：胶囊容器内的图标按钮行：走路 / 骑车 / 清单 / 历史。

### 4.2 白名单引导页
标题"🔒 锁屏记录前，先做这一步" + 一句说明 + **五张厂商卡片**（小米/华为/OPPO/vivo/三星，每张：品牌名 + 设置路径文案）+ 底部全宽主按钮"我已完成设置，开始拜年"。

### 4.3 历史列表页
顶部：返回 + 标题"历史记录"；导出 JSON / 导入 JSON 两个按钮 + 一句互通说明；列表：每场会话一张卡（📅 日期 · 户数 · 距离 · 绕路率），点击进回顾页；空态文案"还没有记录。大年初一，出发！"。

### 4.4 回顾页（拜年后主战场）
1. 顶栏：返回 + "YYYY-MM-DD · 拜年复盘" + 「三线对比」按钮；
2. **回放画布卡**：白色纸感底 + 红色轨迹描边推进 + 白色行进光点（金边）+ 节点圆点与户名标签；
3. 播放控制：播放/暂停、重置、1x/2x/4x、进度"0分0秒/45分"；
4. 收拾区（卡片分组，每组一个标题）：户名与收拾（改名输入行+拆第 N 次）、合并两户（**点选芯片**：选中高亮红色、提示行显示"将把 XX 并入 XX"）、异常跳变点（剔除列表）；
5. 漏访检查：红色大字"❌ 大伯家没去！"或绿色"✅ 全部到访"；
6. 套用去年的户名：每户一行候选芯片（"大伯家（35m）"），点击即套用。

### 4.5 三线对比页（压轴页）
1. 顶栏：返回 + 日期 + "三线对比"；
2. **成绩单四卡**：🧧今年实走（距离/路上/骑行/全天）· 🚶时间最优（省 X%）· 📏距离最优 · ✈️如果能飞（少走 X%）；
3. **画布卡**：淡红实走轨迹（底纹）+ 当前模式路线（实线=实走、虚线=估算）+ 节点序号标注；三个标签切换（走路时间最优/走路距离最优/飞行最优）；
4. 按钮：▶ 推演（逐段点亮 0.35s/段）· ✨ 压轴动画（实走轨迹 3 秒缓动 morph 成金色直线星图）· 重置；
5. 底部说明行："虚线 = 今年没走过的路段（估算）"。

### 4.6 清单管理页
顶栏：返回 + "2027 年拜年清单"；说明一句；「📥 从去年导入」「添加」按钮 + 新户名输入行；清单条目行（序号 + 名字输入框 + 改名 + 删除）；空态提示。

## 5. 按钮状态规则（置灰矩阵，必须严格实现）

**通用**：不可用 = `enabled=false` → 视觉置灰半透明 + 无点击响应；主按钮在状态切换时**替换文案而非叠加**。

| 页面 | 按钮 | 可用条件 |
|---|---|---|
| 记录页 | 开始拜年 | 待机（无会话） |
| 记录页 | 暂停 | 记录中 |
| 记录页 | 继续出发 | 在某户 |
| 记录页 | 结束拜年 | 记录中 或 在某户 |
| 记录页 | 撤销 | 记录中 或 在某户 |
| 记录页 | 走路/骑车 | **仅记录中/在某户**；待机与已保存时置灰 |
| 记录页 | 清单/历史 | 始终可用 |
| 回顾页 | 合并所选两户 | 已点选两户芯片（否则置灰） |
| 回顾页 | 改名 | 输入内容与原名不同 |
| 其它 | 拆分/剔除/播放 | 有对应数据时可用 |

## 6. 设计红线（不可违反）

1. 不改任何功能逻辑与文案语义（按钮文字、提示语保留）；
2. 保留全部按钮的标识与数据流（列表见 §5）；
3. 白天暖色，禁止暗色主题；禁止 emoji 按钮图标；禁止装饰抢主体；
4. 动效时长约束：推演 0.35s/段、压轴 morph 3s（easeInOutCubic）、回放默认 2x、toast 约 2.4s；
5. 字号/对比度保证可读性（户外强光下也能看清状态大字）。

## 7. 交付物建议

1. **设计 token 表**：颜色/字号/间距/圆角/阴影的完整定义（Compose `UiTheme` 可直接落地）；
2. **逐页 Compose 高保真代码**（或等效设计稿）：6 页 + 全部按钮状态（正常/按下/禁用）；
3. 组件清单：主按钮、幽灵按钮、玻璃卡、统计卡、芯片（含选中态）、地图卡、toast。

## 8. 验收标准

- 6 页全部覆盖、按钮置灰矩阵逐条命中；
- 白天暖色年味基调成立、无 emoji 图标、装饰不抢戏；
- 压轴动画帧率流畅（180 点 Canvas）；
- 代码可直接替换现有 Screen 而不破坏功能（编译 + 全量测试通过）。
