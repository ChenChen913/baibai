# baibai（拜拜）· Android 手机 App · UI 设计提示词

> **给 UI 设计 AI 的第一句话：这是一个【安卓手机】上运行的【原生 App】（Jetpack Compose），不是网页、不是小程序、不是桌面软件。请以手机竖屏单手操作为第一设计前提。**
>
> 本文件是完整设计需求：先读业务（§1~§3），再按平台规范（§4）、设计语言（§5）、组件规范（§6）、逐页要求（§7）输出；状态规则（§8）与动效（§9）必须精确实现；红线（§10）不可违反；交付物与验收见 §11~§12。附录（§13）有状态机、术语与图标清单。
>
> **关于图标：本文所有界面文案均为纯文本描述。图标、图形符号、点缀元素（含按钮图标、状态图标、装饰图案）一律由你（设计 AI）自行设计选用——统一用线性 SVG 风格即可，本文不会指定任何具体 emoji。**

## 1. 项目概况（30 秒理解业务）

**baibai（拜拜）**：乡村拜年轨迹复盘玩具。大年初一走村串户拜年时，**安卓手机锁屏揣兜里**持续记录真实行走轨迹：到一户按「暂停」、离开按「继续」；拜完年后回放当日路线，用路径规划算法算出"当日最优走法"与"飞行直线最优"，三线动画对比——**看看自己今年绕了多少路**。

- **唯一用户**：作者本人（个人工具，单人使用）；
- **核心使用场景**：① 出门前看清单；② 拜年中（手机可能揣兜里、锁屏，只偶尔掏出来按一个键）；③ 拜年后回家复盘（回放/收拾/三线对比/压轴动画）；
- **情感基调**：春节的喜庆 + 数据的爽感 + **高级感**（不是卡通、不是廉价、不是"工具感"）；
- **双端关系**：网页版（电脑上复盘/演示）+ 安卓版（现场记录主力）。本提示词针对**安卓版**，但设计语言与网页版一致。

## 2. 现状与问题

现有安卓版已实现全部功能、逻辑正确，但 UI 是"功能堆出来的"：按钮堆叠、间距随意、层次不清、部分图标生硬。**任务：只做视觉与交互质感升级，功能逻辑、页面数量、按钮语义一律不动。**

## 3. 一天的使用旅程（设计时请在心里走一遍）

```
08:00 出门前：打开 App（记录页）→ 点「清单」看一眼今年要去的户
08:10 点「开始拜年」→（首次）白名单引导页 → 授权定位 → 状态卡显示"记录中"
08:15 走到大伯家 → 点「到一户了 · 暂停」（户数 +1，通知栏文案变化）
08:20 离开 → 点「继续出发」……如此循环 15 户
11:30 回家 → 点「结束拜年」→ 自动进入回顾页
11:31 回顾页：看回放 → 给户改名 → 点「三线对比」
11:32 三线对比页：看成绩单 → 「推演」→「压轴动画」→ 截图发朋友圈
```

## 4. 平台与设备规范（安卓手机专属，务必遵守）

| 项 | 规范 |
|---|---|
| 形态 | **安卓手机原生 App**（Compose + Material3），**竖屏为主**（可锁 portrait），不做横屏适配 |
| 屏幕宽度基准 | 主流 360~412dp；布局自适应该区间，**不得超出屏幕、不得左右溢出** |
| 单手操作 | 主按钮位于**拇指热区**（屏幕下半部）；主按钮高度 ≥56dp、全宽；次要操作可双拇指 |
| 点击热区 | **所有可点元素 ≥48dp**（含图标按钮、芯片、列表项）；行间距 ≥8dp 防误触 |
| 单位 | 尺寸 dp、字号 sp；字号随系统字体缩放仍可读（单行不截断、可换行） |
| 系统栏 | 状态栏浅色背景（#FFF8EE）配深色图标；不采用 edge-to-edge 全屏；预留系统导航栏高度，底部内容不被手势条遮挡 |
| 返回 | 每页左上角「返回」按钮 + 支持系统返回手势（行为一致） |
| 权限弹窗 | 定位/通知授权使用**系统原生对话框**（只设计引导文案，不设计弹窗样式） |
| 常驻通知 | 记录期间通知栏有一条**系统通知**（见 §7.7），需设计其小图标与文案模板 |
| 离线 | 纯本地应用，**禁止远程字体/远程图片**；一切资源内置 |
| 无障碍 | 所有图标按钮提供 contentDescription；正文对比度 ≥4.5:1；震动反馈仅在关键动作 |

## 5. 设计语言总纲（Token 表）

**基调：白天暖色年味**——明亮、温暖、喜庆、克制。**禁止暗色/黑夜模式**（拜年是大白天，用户原话）。

| Token | 值 |
|---|---|
| 背景渐变 | 米白 `#FFF8EE` → 淡橙 `#FFE9D4` → 浅杏 `#FFDFC2`（160° 线性，可叠极淡径向暖光） |
| 主色 | 朱红 `#C8402F`（主操作/强调/轨迹线） |
| 辅色 | 鎏金 `#E8A23D`（次级/高亮/压轴/家标记） |
| 文字主 | 墨棕 `#5A3A2A` |
| 文字次 | `#5A3A2A @ 60~70%` 透明度 |
| 危险 | `#B3261E`（漏访标红） |
| 卡片 | 白底半透明 ~66% + backdrop 模糊 + 1px 暖色描边（`#C8402F @ 16%`）+ 圆角 22dp + 阴影（`#5A3A2A @ 10%`，偏移 0/8，半径 24） |
| 圆角 | 卡片 22dp / 小卡 14~16dp / 按钮与芯片胶囊（全圆） |
| 间距 | 页面边距 20dp；区块间距 14~16dp；行内间距 8~10dp |
| 字号 | 状态大字 30sp/800 · 页面标题 17~18sp/800 · 卡片标题 15sp/700 · 正文 14~15sp · 辅助 12~13sp · 注释 11sp |
| 数字 | 统计大数字 24~26sp/700 + **等宽数字**（tabular） |
| 主按钮 | 红→橙→金横向渐变、全宽、高 56dp+、胶囊、按压缩放 0.97、阴影 `#C8402F @ 30%` |
| 图标 | **线性 SVG**：24 viewBox、描边 1.8、圆角端点、随文字颜色（currentColor）；图标由设计 AI 自选（见文首说明） |
| 装饰 | 页面边缘虚化低透明（~20%）的礼花/炮仗图案，最多两样、不进主体、pointer-events 禁用 |
| 字体 | 系统默认字体（PingFang/MiSans/HarmonyOS Sans 等），**不引入远程字体** |

| 组件 | 规范 |
|---|---|
| 主按钮 | §5 规范；**同一时刻只显示一个主按钮**（按状态替换文案，见 §8） |

| 轻提示 | 底部居中胶囊：墨棕 94% 底、白字、约 2.4s 自动消失、带轻微上浮动画 |
| 对话框 | Material3 AlertDialog（暖色主题）：标题 18sp/800、正文 14sp、确认=主色、取消=墨棕 |
| 空态 | 居中一句文案（墨棕 60%）+ 可配一枚线性小图标 |
| 系统通知 | 小图标：单色描边"定位/记录"图形；标题"拜拜 · 拜年记录"；正文动态：`记录中 · 已拜访 N 户` / `在某户 · 已拜访 N 户`；不可滑动删除 |

## 7. 逐页详细设计（共 6 页 + 1 条系统通知）

### 7.1 记录页（驾驶舱 · 主页面）
**从上到下**：
1. **品牌栏**：左 品牌名「拜拜」+ 小字"拜年轨迹复盘"（品牌图标由设计 AI 自选，如灯笼/福字意象）；右金色描边徽章「大年初一」；
2. **状态大卡**（玻璃卡，整页视觉焦点）：
   - 状态大字：`待机 / 记录中 / 在某户 / 已保存`；
   - 副文案一行（随状态变化）：待机=`从家门口出发，按「开始拜年」`；记录中/在某户=`已定位 · 精度约 ±X 米`（X>100 时追加"（网络粗略定位）"）或`正在获取定位…`；已保存=`本次拜年已保存`；
   - 两列大数字：`拜访户数` / `本次用时（HH:MM:SS）`，中间细竖分隔线；
3. **实时地图卡**（**必需组件**，圆角 22dp，位于状态卡与主按钮之间）：
   - **真地图**：高德/OSM 真实地图瓦片（不是示意图、不是装饰），默认展开，高度约 260dp；
   - **可隐藏/可展示**：地图卡右上角一个折叠切换按钮（线性图标，如"地图/收起箭头"，由设计 AI 自选）；折叠后仅剩一条 40dp 高的标题条，再点展开——记录、复盘全程随时可切换；
   - 地图元素：红色当前定位点（白描边）+ **精度圈**（半径=定位误差）+ **实时红色轨迹线**（随走动实时增长）+ 金色圆标「家」+ 红圈数字户标记（悬浮显示户名）；
   - 底部 11sp 版权注：`© OpenStreetMap / 高德地图`；
   - 断网时：已缓存的瓦片继续显示；无瓦片时灰底兜底，**轨迹与标记始终正常绘制**；
   - 待机时：地图显示默认位置（可显示最后一次记录的 Home 或当前定位）。
4. **主按钮区**（拇指热区）：按状态只显示一个主按钮（文案见 §8）；下方一行小按钮：`结束拜年`（记录中/在某户）· `撤销`（记录中/在某户）；
5. **工具条**：胶囊容器内四个图标按钮：`走路 · 骑车 · 清单 · 历史`（走路/骑车带选中态；图标由设计 AI 自选）。

> **实现注**：安卓版地图为**必需功能**（用户要求"真地图、可隐藏、实时轨迹"），接高德地图 SDK（申请指引见 `android/高德接入指引.md`）；网页版已用 Leaflet + OSM 实现同样形态，可作视觉参照。

### 7.2 白名单引导页（首次开始前出现一次）
- 标题「锁屏记录前，先做这一步」+ 一句说明（安卓省电策略可能杀掉后台，加入白名单后锁屏揣兜也能记录）；
- **五张厂商卡片**（小米/红米 · 华为/荣耀 · OPPO/一加 · vivo/iQOO · 三星），每张 = 品牌名（主色加粗）+ 设置路径文案（12sp 次要色）；
- 底部主按钮「我已完成设置，开始拜年」（点击后进入授权/记录流程，本页不再出现）。

### 7.3 历史列表页
- 顶栏：「返回」+ 标题「历史记录」；
- 操作行：主按钮 `导出 JSON` + 幽灵按钮 `导入 JSON` + 一行 11sp 说明"导出/导入与网页版同一格式：安卓记录 → 电脑复盘，或反之"；
- 列表：每场会话一张小卡（日期 + 副行：`N 户 · X.XX km · 绕路率 Y%`），点击进回顾页；按日期倒序；
- 空态：「还没有记录。大年初一，出发！」；
- 导入成功后轻提示「已导入 N 场拜年记录」。

### 7.4 回顾页（拜年后主战场）
1. 顶栏：「返回」+「YYYY-MM-DD · 拜年复盘」+ 右侧主色按钮「三线对比」；
2. **回放画布卡**：白色纸感底；红色轨迹底纹（~20% 透明度）+ 已播放部分实红描边推进（4dp 圆角端点）+ 白色行进光点（金描边 3dp）+ 户节点（白底红描边圆 + 名字标签）+ 金色「家」标记；
3. 播放控制行：`播放/暂停`（主色，图标由设计 AI 自选）· `重置`（幽灵）· `1x / 2x / 4x`（幽灵，当前档高亮）· 右侧进度文字 `0分0秒/45分`（等宽）；
4. **收拾区**（卡片分组，每组标题带金色竖条）：
   - `户名与收拾`：每户一行 = 编号 + 输入框（placeholder"起个名（如大伯家）"）+ 主色小按钮 `改名`（内容未变时置灰）+ 到访≥2 次时出现 `拆第 N 次（HH:mm）` 小按钮；
   - `合并两户（误拆并为一户时）`：提示行"点选两户：第一个保留，第二个并入" + 芯片组（选中红底白字）+ 主色按钮 `合并所选两户`（未选满两户置灰）；选中两户后提示行变为"将把「B」并入「A」（名字/编号保留前者）"；
   - `异常跳变点`：`剔除全部（N 个）`（金色按钮）+ 逐条 `HH:mm · 精度 Xm` + 幽灵小按钮 `剔除`；无跳变显示"无异常跳变点"；
5. **漏访检查（今年清单）**：无清单→"今年还没有清单。回记录页 →「清单」先导入/添加。"；有清单全到访→"清单 N 户全部到访，没有漏拜！"（绿色成功样式，图标由设计 AI 自选）；有漏访→红色加粗 `疑似漏访 N 户` + 逐条 `XX 没去！`（无坐标户追加"（无坐标·手动核对）"）；
6. **套用去年的户名**：说明行 + 每户一行候选芯片（`大伯家（35m）`，按距离排序取前 3），点击立即套用并保存；无往年记录→"没有往年记录可套用。"

### 7.5 三线对比页（压轴页）
1. 顶栏：「返回」+「YYYY-MM-DD · 三线对比」；
2. **成绩单四卡**（每卡：标题 13sp + 数据行 17sp/700 主色；标题图标由设计 AI 自选）：
   - 今年实走：`X.XX km / 路上 Y 分 Z 秒 · 骑行 X.XX km · 全天 Y 分 Z 秒`；
   - 走路时间最优（理论）：`Y 分 Z 秒 / 比实走路上时间省 X%`；
   - 距离最优：`X.XX km / 省 X%`；
   - 如果能飞：`X.XX km / 少走 X%`；
3. **画布卡**：淡红实走轨迹（30% 透明度底纹）+ 当前模式路线（**实线=实走数据、虚线=估算段**）+ 节点与序号标注（家=金色大圆，其余=白底描边圆 + 顺序数字）；三个标签切换：`走路时间最优（红）/ 走路距离最优（橙）/ 飞行最优（金）`，当前标签用对应颜色高亮；
4. 按钮行：`推演`（主色）· `压轴动画`（金色）· `重置`（幽灵）；
5. 底部说明行：飞行模式→"飞行视角：直线距离，纯几何幻想"；其它→"虚线 = 今年没走过的路段（估算）；实线 = 实走数据"。

### 7.6 清单管理页
- 顶栏：「返回」+「YYYY 年拜年清单」；
- 说明行："出门前看一眼，拜年时照常只按「暂停」，回来系统自动对比漏了谁。"；
- 操作行：主色按钮 `从去年导入` + 幽灵按钮 `添加` + 输入行（placeholder"新户名字（无坐标，仅提醒）"）；
- 条目行：序号 + 输入框 + 主色小按钮 `改名`（未变置灰）+ 幽灵 `删除`；无坐标户条目旁小注"无位置·手动核对"；
- 导入确认对话框："从 YYYY-MM-DD 的 N 户生成清单？（会覆盖当前清单）"；
- 空态："清单为空：点「从去年导入」或手动添加"。

### 7.7 系统常驻通知（记录期间）
- 小图标：线性风格"定位/记录"图形（单色，由设计 AI 设计）；
- 标题固定：`拜拜 · 拜年记录`；正文动态：`记录中 · 已拜访 N 户` / `在某户 · 已拜访 N 户`；
- 不可滑动删除（ongoing）；点击通知回到记录页。

### 7.8 全局对话框（三种，文案必须一字不差）
1. **崩溃恢复确认**（App 启动发现未完成记录时）：标题「检测到未完成的拜年记录」· 正文「继续记录，还是放弃？」· 按钮 `继续`（主色）/ `放弃`；
2. **结束距离确认**（结束拜年时距家较远）：标题「距 Home 约 X 米」· 正文「当前位置离出发点较远，仍要结束本次拜年吗？」· 按钮 `强制结束`（主色）/ `取消`；
3. **清单导入确认**：标题「从去年导入」· 正文「从 YYYY-MM-DD 的 N 户生成清单？（会覆盖当前清单）」· 按钮 `导入`（主色）/ `取消`；无历史数据时正文为「还没有历史拜年记录，无法导入。」（仅 `取消`）。

> 另：定位/通知授权弹窗由**系统**呈现，无需设计样式，只需保证引导文案友好。

## 8. 按钮状态规则（置灰矩阵，逐条实现）

**通用**：不可用 = 置灰 + 半透明（38%）+ 无点击响应；主按钮按状态**替换文案**而非叠加。

| 页面 | 按钮 | 可用条件 | 禁用时表现 |
|---|---|---|---|
| 记录页 | 开始拜年 | 待机（无会话） | 其它状态不显示 |
| 记录页 | 到一户了·暂停 | 记录中 | 其它状态不显示 |
| 记录页 | 继续出发 | 在某户 | 其它状态不显示 |
| 记录页 | 结束拜年 | 记录中 或 在某户 | 其它状态不显示 |
| 记录页 | 撤销 | 记录中 或 在某户 | 其它状态不显示 |
| 记录页 | 走路 / 骑车 | **仅记录中/在某户**；待机、已保存 → 置灰 | 置灰 |
| 记录页 | 清单 / 历史 | 始终可用 | — |
| 记录页 | 地图折叠切换 | 始终可用 | — |
| 回顾页 | 合并所选两户 | 已点选两户芯片 | 置灰 |
| 回顾页 | 改名 | 输入内容 ≠ 原名 | 置灰 |
| 回顾页 | 拆分 | 该户到访 ≥2 次 | 不显示 |
| 回顾页 | 剔除 | 存在跳变点 | 不显示 |
| 清单页 | 添加 | 输入非空 | 置灰 |
| 清单页 | 改名 | 输入内容 ≠ 原名 | 置灰 |
| 三线页 | 推演/压轴/重置 | 始终可用 | — |

**状态机与文案对照**：`IDLE→开始拜年`、`WALKING→到一户了 · 暂停 / 结束拜年 / 撤销`、`PAUSED→继续出发 / 结束拜年 / 撤销`、`FINISHED→（自动跳转回顾页）`。

## 9. 动效规格（精确参数）

| 动效 | 参数 |
|---|---|
| 按钮按压 | 缩放 0.97，120ms ease-out，松开回弹 |
| 轻提示 | 上浮 12dp + 淡入，2400ms 后淡出 |
| 轨迹回放 | 描边沿路径推进（PathMeasure 分段）+ 光点平滑插值；默认 2x，可选 1x/2x/4x |
| 三线推演 | 逐段点亮，每段 350ms，全程 ≤ n×350ms |
| 压轴 morph | **3 秒**、easeInOutCubic、180 点重采样：实走轨迹逐点插值变形为金色直线星图，节点在收尾时轻微放大脉冲 |
| 页面切换 | 淡入 150ms（或默认系统过渡），无花哨 |
| 芯片选中 | 背景色 120ms 渐变 + 轻弹 |
| 地图折叠 | 高度过渡 180ms ease-out |
| 震动 | 开始/暂停/继续/结束各 50ms |

## 10. 设计红线（不可违反）

1. **这是安卓手机 App**：竖屏、单手、≥48dp 热区、系统导航/状态栏适配；
2. 不改任何功能逻辑、页面数量与文案语义（按钮文字、提示语、数据口径保留）；
3. 白天暖色年味；**禁止暗色主题**；图标一律线性 SVG（本文不指定 emoji，由你自选）；装饰不抢主体；
4. 离线可用：禁止远程字体/图片/CDN 资源；
5. 动效参数按 §9 精确实现，不得擅自延长/缩短关键动画（压轴 3s 是体验核心）；
6. 强光可读性：状态大字与统计数字在户外阳光下清晰（对比度 ≥4.5:1，字号不缩水）；
7. 替换现有 Compose Screen 后必须**编译通过 + 全部功能测试通过**（按钮 id/回调语义一一对应）。
