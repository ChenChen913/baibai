| 08-21 | **v1.0.10 朝向「探照灯」（版本码 7）** | 仿高德/百度：手机朝哪儿，地图当前位置点就向哪个方向打出一束高德式蓝色光锥（60° 扇形、边缘径向淡出），随手机旋转实时平滑转动。实现：安卓 `ROTATION_VECTOR` 传感器（系统融合磁力计+加速度计）→ 纯四元数数学取「用户视线（设备 -Z 轴）的水平投影方位」→ `GeomagneticField` 按当前位置磁偏角校正成真北 → 经 JS 桥 `BaibaiMap.setHeading` 只改光锥 `transform`（不重建 DOM、不重绘地图）→ JS 侧低通滤波（α=0.35）+ 最短弧插值（359°→1° 顺转 2° 不逆转）。关键取舍：不用官方 compass 的 `remapCoordinateSystem(AXIS_X,AXIS_Z)+getOrientation` 写法（其给出屏幕法线方位，竖持面北会差半圈）；节流 15Hz + 变化 ≥2° 才推；进记录页注册传感器/离开注销（省电）；无传感器设备（老机型/模拟器）光锥静默隐藏。方案设计见 [朝向探照灯方案.md](./docs/朝向探照灯方案.md) |
