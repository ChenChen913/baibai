# M5 视觉精修与 PWA · SPEC（开发规格 v1）

> 对应《项目需求文档.md》里程碑 M5。部署（GitHub Pages）工作流已在仓库就绪，只差仓库名与推送。

## 1. 视觉精修（D21 落地）

- **基调**：浅暖色底（米白→淡橙渐变）+ 红色系柔和高光；**不做暗色**；
- **装饰**：页面**边缘**点缀虚化、低透明的**礼花 + 炮仗**（各一个 SVG，模糊 1.5px、透明度 ~0.16、pointer-events 禁用，绝不进主体区域）——只用这两样，不堆元素；
- 装饰为静态 HTML 层（先于 JS 渲染，加载即见）。

## 2. PWA 离线（D3/D22）

- `public/manifest.webmanifest`：名称「拜拜」、主题色 `#c8402f`、背景 `#fff7ec`、standalone、图标 192/512 + maskable；
- `public/sw.js`：运行时缓存（首次在线访问即全量入缓存，之后断网可跑）；install 预缓存 `./`，activate 清旧版本；
- 图标：程序化生成（192/512 PNG + 180 apple-touch-icon），灯笼意象（红底圆角 + 金色圆 + 红穗）；
- SW 仅在 `import.meta.env.PROD` 注册（开发环境不缓存，避免 HMR 污染）。

## 3. 验收

- 浏览器 Lighthouse PWA 检查可通过（installable）；断网刷新可完整运行；
- 部署到 Pages 后手机"添加到主屏幕"可全屏运行。
