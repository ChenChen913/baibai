# M3 优化与压轴动画 · SPEC（开发规格 v1）

> 对应《项目需求文档.md》里程碑 M3。范围：三线优化算法层（本轮）+ 三线动画/压轴 morph/成绩单 UI（下一轮）。

## 1. 边权矩阵（D8/D14/D15）

| 线 | 已知边（当日实走过） | 未知边 | 标注 |
|---|---|---|---|
| **飞行线** | — | haversine 直线距离 | 全图几何精确，UI 无需实/虚区分 |
| **距离线** | 当日最短实走距离（同一对多次取 min，D15） | 直线 × **1.3** 绕行系数 | 未知边标"估算"（UI 虚线） |
| **时间线** | 最短实际行程时间（= arriveT − departT，departT = 上一户 leaveT；同对取 min） | 估算距离 ÷ **步行 4.86km/h**（未知边一律按走路） | 未知边标"估算" |

- 图按**无向**处理（A→B 与 B→A 同权，取两方向各自数据的最小者）；
- 起点固定为 **home**（D9），求解"走遍全部农户回 home"的闭环。

## 2. 求解器（tsp.ts）

- **Held-Karp 动态规划**（固定起点），`n ≤ 16` 精确解（内存 ~16MB，浏览器可接受）；
- `n > 16` 退化为 **贪心最近邻 + 2-opt**，结果标 `exact: false`（村庄户数预期 10~20，16 以内即精确）；
- 输出：`{ order: number[], cost: number, exact: boolean }`（order 不含重复起点，调用方自行闭合）。

## 3. 路由输出（optimize.ts）

```ts
interface RouteEdge { from: string; to: string; known: boolean; }
interface Route {
  mode: 'fly' | 'walk_dist' | 'walk_time';
  order: string[];      // home 打头，不含闭合重复
  cost: number;         // 米 或 秒
  exact: boolean;
  edges: RouteEdge[];   // 含闭合边（最后一户→home）
}
```

## 4. 演示数据生成器（demo.ts，本轮实现——回顾页验收依赖它）

- 8 户 + home，日期 **2026-02-17（丙午年春节）**，出发点 08:00；
- 实走顺序**故意绕路**（1→3→6→7→2→8→4→5）保证三线对比有戏剧性；
- 轨迹带正弦弯曲、1 段骑行、1 个跳变点（演示剔除）；确定性输出，可单测。

## 5. 测试清单（vitest，本轮全做）

1. tsp：与全排列暴力解对比（n=6 随机 10 组）；返回合法排列（0 起、全节点恰好一次）；
2. tsp：n>16 走启发式，`exact:false` 且排列合法；
3. optimize：飞行线 cost = 边权和（haversine）；已知对取 min（同对多次）；未知边 = 直线×1.3；时间未知边 = 距离÷速度；空会话返回 home 单点零成本；
4. demo：节点/访问数、时间单调、总时长>0、buildEdges 与 optimizeSession 均可消费。
